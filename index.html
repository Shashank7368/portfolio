Advanced AI Medical Intelligence Platform

Jul 2026

An end-to-end platform that classifies chest X-rays as Normal or Pneumonia, shows why with a heatmap, and drafts a radiology-style report.

  • ResNet-18 transfer-learning classifier in PyTorch with augmentation and best-checkpoint saving
  • Grad-CAM written from scratch with forward and backward hooks
  • Claude API report generator with a clinical disclaimer and a no-key fallback
  • FastAPI REST endpoints (predict, history, report, health) with Swagger docs
  • SQLAlchemy history store, Docker and docker-compose packaging, 5 passing pytest tests

Trained on a synthetic demo dataset because the real dataset was unreachable at build time. The pipeline is built to run on the Kermany chest X-ray dataset unchanged.
